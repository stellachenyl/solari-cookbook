=== error classes ===
  ActionError: A computer-use RPC returned ``{ok:false}``.
  AuthError: ``401`` — the API key was missing, malformed, or rejected.
  ConcurrencyLimitError: ``429 {code:"ConcurrencyLimitExceeded"}`` — too many live desktops.
  ConnectionError: The control WebSocket is not open (never connected, or closed).
  GatewayError: Any non-2xx response from the gateway that isn't otherwise specialized.
  NoCapacityError: ``503`` — no desktop host currently available to serve the request.
  PlanError: ``402 {code:"FeatureRequiresPlan"}`` — the plan doesn't allow this.
  SolariError: Base class for every error thrown by the SDK.
  TimeoutError: An RPC did not receive a reply within the per-call timeout.
